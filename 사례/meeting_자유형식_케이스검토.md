# meeting 자유형식 편집 — 사용자 케이스 사전 검토 (2026-11-13)

대상: v2e-studio(PPT형 단일 슬라이드, 개체 자유 편집)를 원본 meeting에 넣을 때, 이슈와 연결된 개체를 사용자가 어떻게 다루는지.
방법: 역할별로 "사용자가 하려는 것 → 기대하는 결과 → 처음 안(값을 고치면 이슈 반영)으로는 어떻게 되나 → 문제 → 제안"을 따라간다.
출발점이 된 질문: "개체에 「원인」 소제목이 붙어 있고 이슈와 연결돼 있는데, 소제목을 고치면?" (→ 1번)

역할: 작성자(과장·호선 담당자) · 부서 편집자(부장·부서 스텝) · 기획(팀 스텝·기획 주관자) · 회의 진행자

## 1. 케이스

### A. 연결된 개체를 고칠 때
| # | 누가 | 하려는 것 | 기대 | 처음 안이면 | 문제 | 제안 |
|---|---|---|---|---|---|---|
| A1 | 부서 편집자 | 소제목 「원인」→「추정 원인」 | 이 자료만 이름 바뀜 | 연결은 칸 기준이라 유지 | 없음 | 소제목은 표현. 개체를 소제목·값으로 나눈다(지금 시안은 한 덩어리) |
| A2 | 부서 편집자 | 긴 원인을 회의용으로 **줄임** ("조사 중 — 자매선 SN2510 분사밸브 노즐 마모" → "노즐 마모 추정") | 이 자료만 짧게 | **이슈의 자세한 원인이 짧은 문장으로 덮임**, 작성자에게 알림 | 가장 흔한 편집이 사실 훼손이 된다 | 캔버스에서 고친 값은 **이 자료만**(표현). 개체에 「이슈와 다름」 표시 |
| A3 | 부서 편집자 | 원인 **오타** 고침 | 이슈도 고쳐짐 | 반영됨 | A2와 같은 손동작인데 기대가 반대 | 「이슈에도 반영」을 따로 한 번 누르게 (오른쪽 사실 칸 또는 「이슈와 다름」 칩에서) |
| A4 | 부서 편집자 | 원인 칸에 조치까지 한 문단으로 씀 | 보기 좋게 | 이슈 원인에 조치가 섞임 | 칸 오염 → 지식창고·사례 카드 품질 저하 | A2 규칙이면 이 자료만. 이슈 반영은 사실 칸에서 칸별로 |
| A5 | 누구나 | 연결 개체를 Ctrl+C/V로 복사 | 같은 글 하나 더 | 연결이 둘? | 한 칸에 개체 두 개 연결되면 어느 쪽이 정답인지 모호 | 붙여넣은 것은 **연결 없는 자유 글** |
| A6 | 누구나 | 연결 개체 통째로 삭제 | 이 장에서만 빠짐 | 이슈 칸은 그대로 | 없음 | 오른쪽 「연결 칸」 목록에서 다시 넣기 |
| A7 | 누구나 | 사진 개체 자르기·밝기 | 이 장에서만 | 원본 사진 그대로 | 없음 (원칙 1: 원본은 안 바꿈) | 유지 |
| A8 | 누구나 | 연결 개체 소제목을 「조치」로 바꿈 (실수) | — | 값은 여전히 원인과 연결 | 화면 이름과 실제 연결이 어긋남 | 개체를 고르면 칩 「이슈 원인 · ISS-…」 표시 |

## 2. 검토로 바뀐 것
처음 안("캔버스에서 값을 고치면 이슈에 반영")은 **A2·A4 때문에 바꾼다.** 회의자료 편집의 대부분은 줄이기·다듬기인데, 그게 이슈 원문을 덮게 된다.

**바뀐 안: 「캔버스는 자료만, 사실은 사실 칸에서」** (원본 v2m의 「회의용 한 줄 = 자료만 / ● 사실 = 이슈 반영」 구분을 그대로 이어감)
- 캔버스에서 고치는 것(글·소제목·배치·서식)은 모두 **이 자료만**. 연결 개체 값을 고치면 「이슈와 다름」 칩
- 이슈를 바꾸는 길은 둘: 오른쪽 **사실 칸**에서 고치기, 또는 「이슈와 다름」 칩의 **「이슈에도 반영」**. 이때 작성자 알림 + 되돌리기
- 연결은 이슈 칸 기준, 소제목은 꾸밈, 복사본·요약 장은 연결 없음

## 3. 정해야 할 것
| # | 질문 | 추천 |
|---|---|---|
| Q1 | 캔버스에서 연결 값을 고치면 기본이 「자료만」인가 「이슈 반영」인가 | 자료만 (2절) |
| Q2 | 형태를 바꾸면 꾸민 것을 버리고 새로 그리나 | 새로 그림 + 되돌리기 (B1) |
| Q3 | 이어받은 자유 글·「이슈와 다름」을 제출 전에 어떻게 알리나 | 표시 + 남은 수 안내, 막지는 않음 (C1·C2) |
| Q4 | 같은 자료 동시 편집 | 한 명씩, 뒤엣사람 읽기 전용 (D4) |
| Q5 | 범위: A 전부 자유형식 / B 2차로 / C 장마다 「자유 편집」 켜기 | Q1~Q4가 정해지면 A·C 모두 가능. 일정 우선이면 B |

## 4. 확인하지 못한 것
- 실제 부서 편집자가 무엇을 가장 많이 고치는지(줄이기·순서·사진 강조 비율) — 지난 회의 PPT 몇 주치를 비교하면 알 수 있다
- 회의 직전 몇 분에 몰리는 편집량
